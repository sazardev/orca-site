Before you start

Orca is in private alpha. The repository and the app are shared by invitation, so the two links below — the repository and the APK — arrive with your invite. This page walks the whole path once you have them.

Nothing here asks you to open a port to the internet. Orca only listens on 127.0.0.1 of your PC; Tailscale carries it to your own devices.

What the PC needs

  • Linux with Herdr, the terminal workspace manager your agents run in.
  • Claude Code and/or OpenCode, already working in Herdr.
  • Python 3 (standard library only: nothing to pip install).
  • Tailscale, signed in to your tailnet.
  • Optional: git (branches and worktrees), gh (your GitHub repositories, creating and cloning), zoxide (the folders you visit).

The server

Get the repository from your invite and run the server as a user service, so it starts with your session and restarts if it stops.

shell
# once
git clone <the repository from your invite> ~/orca
mkdir -p ~/.config/systemd/user
~/.config/systemd/user/orca-server.service
[Unit]
Description=Orca server

[Service]
ExecStart=/usr/bin/python3 %h/orca/server/orca_server.py
Environment=ORCA_ALLOWED_LOGIN=you@example.com
Restart=on-failure

[Install]
WantedBy=default.target

ORCA_ALLOWED_LOGIN is the Tailscale identity that may use the server: Tailscale tells it who is calling, and anyone else is refused.

shell
systemctl --user daemon-reload
systemctl --user enable --now orca-server
# after pulling a new version
systemctl --user restart orca-server

Reach it over Tailscale

Publish the local port inside your tailnet, with HTTPS. The app only accepts https:// addresses.

shell
tailscale serve --bg --https=8445 http://127.0.0.1:2588
tailscale serve status

The status line shows the address, something like https://your-pc.your-tailnet.ts.net:8445. That is what you will type in the app.

The phone

  • Install Tailscale on the phone and sign in to the same tailnet.
  • Download the APK from your invite. Most current phones want arm64-v8a. Check it against SHA256SUMS.txt before installing.
shell
sha256sum -c SHA256SUMS.txt --ignore-missing

Allow installing from the file manager or browser you used, once. A new version installs over the old one: they share a signing key.

Connect and check

Open Orca, go to Settings and write the server address. The Setup card at the top reads six things and each failing line has a button that opens the right Android screen:

LineWhat it checks
Server addressIt is there and starts with https://.
InternetThe phone is online.
TailscaleInstalled and connected to your tailnet — not just any VPN.
Orca server/v1/health answers, with the Herdr version and the delay.
Notification permissionAndroid lets Orca tell you things.
BatteryOrca is not restricted, so the watcher keeps running.

Notices and the background

In Settings, turn on Notify me and choose when: when an agent needs you, when it finishes, or both. Android asks for permission at that moment.

Orca watches by itself with a small foreground service that asks your server every few seconds. There is no push service in between, so nothing leaves your tailnet. Set the app to Unrestricted in the battery settings, or Android may stop it.

Android shows one small permanent notice while the watcher runs. It lives in its own low-priority channel, so you can hide it.

Android extras

Under Set Up → Android:

  • Widgets: Agents (a list with filters) and Needs you (a count).
  • Quick settings tile and launcher shortcuts: start a new agent in one touch.
  • Bubbles: float an agent from its options, or with the + inside a bubble. Android must allow bubbles for Orca (“all conversations”); the page has a button that opens that setting. Bubbles show only while you are outside the app.

Your first agent

  • Projects: pin a folder, or New project to make one (with a private or public GitHub repository, if gh is signed in).
  • Open it and Start an agent: Claude or OpenCode, in the folder, in a worktree, or in a new one; a mode; a first message.
  • It shows up under Agents, and anything it asks arrives as a notice.
